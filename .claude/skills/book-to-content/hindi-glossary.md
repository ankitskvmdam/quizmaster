# Hindi glossary and question phrasing

Used by the translation phase of `/book-to-content`. Extend the tables when a new subject (geography, economics, …)
brings new terms, so every book uses the same Hindi for the same thing.

Use standard Hindi exam terminology (BPSC/SSC Hindi-medium papers, NCERT Hindi). On the **first use in each chapter
file** (and the first use in a question if the term is the point of the question), put the English term in brackets
after a technical term or act name, e.g. स्थायी बंदोबस्त (Permanent Settlement). Write proper names in Devanagari so
they stay recognisable (जेम्स रेनेल, पेशवा दफ्तर, आनंदमठ); for less familiar names, newspapers, books and paintings you
may add the English in brackets on first use in the gist. Acronyms like INC, RSS, INA, CPI may stay in Roman after
the Hindi name has appeared once (भारतीय राष्ट्रीय कांग्रेस (INC)).

## Standard question phrasing (use these exactly)

| English | Hindi |
|---|---|
| Consider the following statements: | निम्नलिखित कथनों पर विचार कीजिए: |
| Which of the statements given above is/are correct? | उपर्युक्त कथनों में से कौन-सा/से सही है/हैं? |
| Which of the statements given above is/are NOT correct? | उपर्युक्त कथनों में से कौन-सा/से सही नहीं है/हैं? |
| Select the correct answer using the code given below. | नीचे दिए गए कूट का प्रयोग कर सही उत्तर चुनिए। |
| 1 only / 1 and 2 only / 1, 2 and 3 | केवल 1 / केवल 1 और 2 / 1, 2 और 3 |
| Both 1 and 2 / Neither 1 nor 2 | 1 और 2 दोनों / न तो 1, न ही 2 |
| None of the above / All of the above | उपर्युक्त में से कोई नहीं / उपर्युक्त सभी |
| More than one of the above | उपर्युक्त में से एक से अधिक |
| Assertion (A): … / Reason (R): … | कथन (A): … / कारण (R): … |
| Both A and R are true and R is the correct explanation of A | A और R दोनों सही हैं तथा R, A की सही व्याख्या है |
| Both A and R are true but R is not the correct explanation of A | A और R दोनों सही हैं, परंतु R, A की सही व्याख्या नहीं है |
| A is true but R is false / A is false but R is true | A सही है, परंतु R गलत है / A गलत है, परंतु R सही है |
| Arrange the following in chronological order: | निम्नलिखित को कालानुक्रम में व्यवस्थित कीजिए: |
| Match List I with List II: | सूची-I को सूची-II से सुमेलित कीजिए: |
| Which of the following pairs is/are correctly matched? | निम्नलिखित में से कौन-सा/से युग्म सही सुमेलित है/हैं? |
| Who / Which / When … ? | किसने / कौन-सा / कब … ? |

Use the danda (।) as the full stop in Hindi prose.
